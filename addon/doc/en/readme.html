Angel Audio Keeper 0.2.0

Audio Keeper plays very quiet sound while NVDA runs. It may reduce delay or clipped speech caused by a sleeping sound device. Fresh installs start disabled. It does not repair sound drivers or Windows enhancements.

Start

  1. Open NVDA menu, Preferences, Settings, Audio Keeper.
  2. Choose Follow NVDA's configured output, Follow Windows default, One selected output, Several selected outputs, or All active outputs (up to 16).
  3. Leave Noise volume at 5 to begin. Check Enable continuous audio and choose Apply or OK. Use Refresh status to check playback.

Press NVDA+Shift+F12 or choose Stop audio now to stop and save the disabled state. Cancel in the settings dialog does not undo an emergency stop. The shortcut can be changed in Input Gestures.

Choosing outputs

Follow NVDA tracks the output chosen by NVDA, including profile changes. Follow Windows default tracks the Windows multimedia output. One or Several selected outputs keep the named devices active. All active outputs uses every available output, up to 16. Each has an independent stream. A disconnected device is retried without stopping healthy outputs. All active outputs can use more power and play on speakers you are not using.

Noise volume affects only Audio Keeper. Start low and increase gradually if needed. Zero sends silence, which may not keep hardware awake. Separate noise is generated for each exposed channel; a stereo device remains stereo.

Other options

Computer and display keep-awake requests are separate, off by default, and normally withheld on battery. Allow battery requests only if you accept the power use. Detailed logging adds activity records; ordinary errors are logged either way. Refresh output list rescans devices. Copy diagnostic summary copies technical status; Open log folder shows local logs.

Upgrade and troubleshooting

Open the 0.2.0 add-on file, accept replacement, and restart NVDA. Settings remain. If status says Waiting to recover, check the selected device. If a receiver exposes only stereo, configure its surround layout in Windows; the add-on cannot create missing channels. Playback stops when NVDA exits. To remove the add-on, disable it, remove it in NVDA's Add-on Store, and restart NVDA.

Logs contain device names, identifiers and errors; review them before sharing. No microphone or speech is recorded and nothing is uploaded. Tested with NVDA 2026.2 on Windows 11 and Realtek stereo. NVDA 2026.1 is the declared minimum; other hardware needs testing. See the project for test details.
