About the add-on

Angel Audio Keeper, by Angels Clan, helps reduce clipped speech and audio wake delays on devices that sleep between sounds. It maintains a separate quiet audio stream even while NVDA is silent. Fresh installations start disabled. This is an initial release, not a guaranteed fix for HP drivers or enhancement resets.

Install or upgrade

Open AngelAudioKeeper-0.1.0.nvda-addon and accept NVDA's installation prompt. For an upgrade, accept replacing the existing copy; do not uninstall it first. Restart NVDA when prompted. A Windows reboot is not required. Settings and logs are preserved, including enabled state and volume. The package is intended for NVDA 2026.1–2026.2; installed playback has been checked on NVDA 2026.2 with Windows 11 and Realtek stereo. NVDA 2026.1 and physical HDMI surround require additional device testing. English is the initial interface language.

Start

  1. Open NVDA menu, Preferences, Settings, Audio Keeper.
  2. Select your speakers or Follow Windows default. Outputs are scanned in the background and the list updates automatically. Refresh output list requests another scan.
  3. Leave noise volume at 5 initially. Enable continuous audio, then Apply or OK.
  4. Use Refresh status: expect Playing, the selected device, channel count and increasing counters.

Press NVDA+Shift+F12 to stop, or use Stop audio now. Stop is saved even if you later cancel the settings dialog. Input gestures under Audio Keeper lets you change the shortcut or assign toggle/status shortcuts.

Options

  • Enable continuous audio: start playback after Apply or OK and on subsequent NVDA starts. Off by default; no background service is installed.
  • Audio output: follow Windows' default multimedia output, or select one named output. A missing named output is retried without switching to another speaker. Windows default changes are checked approximately every two seconds.
  • Noise volume: default 5, adjustable from 0 to 100. This adjusts only the add-on's stream, not speech or Windows master volume.
  • Keep the computer awake: request prevention of automatic idle sleep while playback runs. Off by default.
  • Keep the display awake: separately request prevention of idle display shutdown while playback runs. Off by default.
  • Allow keep-awake requests on battery power: off by default. When off, audio still plays on battery, but the two power requests above are withheld. Enabling it can reduce battery life. No option prevents critical-battery shutdown.
  • Detailed diagnostic logging: off by default. Adds ten-second activity summaries and extra buffer diagnostics; normal summaries are every minute. Errors are logged either way.

Noise volume 0–100 uses a quiet range: 100 is limited to one percent peak digital full scale; 5 is 0.05 percent. Physical loudness depends on your speakers and volume. Zero sends silence, which may not keep a device awake. Independent noise is generated for every supported channel of the selected output by default, not every separate sound device. This includes center, rear, side and LFE channels when the selected HDMI or sound-card output exposes them. Windows and the receiver must be configured for the surround layout; a stereo endpoint cannot produce separate center/rear channels. LFE filtering may make its static less audible. Channel names appear in status and logs. Playback continues while enabled and NVDA runs; a missing output is retried without silently choosing a different speaker.

Computer and display keep-awake are separate optional settings, normally withheld on battery. No Windows power plan is changed. Some drivers treat any active audio stream as a reason not to enter idle sleep. Deliberate sleep/shutdown is not blocked.

Apply/OK saves settings globally for this add-on only. NVDA application-profile switches cannot undo Stop. Volume, logging and power changes leave the audio stream open. Live volume changes use gain on this add-on's stream only, without rebuilding the noise. A device change must reopen it. It does not modify enhancements, NVDA speech volume or master volume.

Buttons and shortcuts

  • Refresh output list: scan devices in the background.
  • Refresh status: update the read-only status and counters. Counters are cumulative for the current worker session.
  • Copy diagnostic summary: copy status and diagnostic paths to your clipboard; no recording is copied.
  • Open log folder: show local diagnostic files.
  • About the add-on: open readable version, purpose and privacy information.
  • Stop audio now: stop and save the disabled state immediately. NVDA+Shift+F12 does the same thing. Cancel does not undo this action.
  • Apply or OK: save and apply edits. Cancel discards unsaved edits, not settings already applied.

Logs

Copy diagnostic summary and Open log folder are in the same settings category. Logs are in angelAudioKeeperLogs under your NVDA configuration directory: at most four files of about 512 KiB each. They contain timestamps, device names/IDs, format, buffer activity, errors and retries. Detailed logging gives ten-second summaries; normal logging gives sixty-second summaries. No microphone, speech or audio recordings are made, and nothing is uploaded. Review device names and paths before sharing logs.

Increasing counters prove output submission, not physical speaker behavior. Empty-refill counts do not necessarily mean an audible glitch.

Test and recovery

If no sound is audible, first check enabled state, the selected device and increasing counters. Quiet noise is intentional. Do not turn the volume up sharply. If status says Waiting to recover, reconnect the selected device or choose another. Retries use bounded backoff up to thirty seconds.

If HDMI shows two channels, Windows is exposing stereo. Configure surround in Windows and on the receiver before expecting center/rear output. This add-on cannot create physical speakers. No physical HDMI surround receiver was available during initial qualification; the generated multichannel signals were software-tested.

If settings cannot be saved, check permissions and disk space. Emergency stop still requests playback stop, but a failed save can let audio restart at the next NVDA launch. Corrupt settings start disabled without automatically overwriting your original settings file. Driver problems may still cause clipping or stutter.

To upgrade from the first test build, open the new package and accept replacement, then restart NVDA when prompted. Do not uninstall first. Your settings and logs are preserved, including the enabled state and selected volume.

Check that other audio and NVDA speech remain normal, then leave speech idle and compare the first words with playback disabled. Note the time if stuttering or enhancement changes return. Existing Bluetooth Audio Active or other keep-audio-awake add-ons are not disabled automatically; disable overlapping add-ons for a clean test if you wish. This package has not been proven to prevent HP enhancement resets.

Disable or remove this add-on using NVDA's Installed Add-ons interface and restart NVDA if prompted. You can start NVDA with --disable-addons for recovery. Settings and small logs are retained. Nothing runs in secure mode or after NVDA exits.

When reporting a problem, include Windows, NVDA and add-on versions, device type, channel layout, steps and approximate time. Share only reviewed diagnostics, not your entire NVDA log or configuration: unrelated sensitive information may be there.
